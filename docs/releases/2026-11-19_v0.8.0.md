# Release Evidence Pack - v0.8.0

**Data da release:** 2026-11-19
**Versão anterior:** v0.7.0
**Responsável:** Carlos Alberto Pereira Gomes

## Resumo Executivo

Release minor com duas funcionalidades para a rotina de visita e
evolução: **exportação XLSX do mapa de enfermaria** (o resultado
filtrado atual vira um workbook pronto para a planilha do round,
substituindo a transcrição manual de leito/identificação/médico/
evolução/conduta) e **diálogo de cópia fragmentada no card da
evolução** (DailyNotes acima de 4.000 caracteres podem ser colados
no sistema do hospital em partes numeradas P1..P4, sem truncamento
silencioso). Dois changes OpenSpec arquivados; **sem migrações de
banco** (migrate no-op esperado no upgrade). Sem mudanças de
permissões, autenticação ou infraestrutura; risco baixo, rollback
de app trivial.

## Rollback Plan

### Cenários para rollback

1. **Falha de health após o upgrade**: o próprio `upgrade.sh`
   imprime o comando de reversão do digest e restaura estáticos da
   versão anterior (`--profile ops run --rm init`).
2. **Bug funcional grave**: reverter o digest no compose e
   recriar; sem migração nesta release, rollback de app é limpo
   (nenhuma mudança de schema).

### Passos para rollback

1. Comando de reversão impresso pelo `upgrade.sh` (digest no
   compose) + `up -d`.
2. `docker compose --profile ops run --rm init` para recompor
   estáticos da versão anterior.
3. Validar login e `/health/`.

**Tempo estimado para rollback:** < 15 minutos.
