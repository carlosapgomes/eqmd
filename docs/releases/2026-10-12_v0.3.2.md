editar"). Numbering restores monotonic order above the previously
untracked tags `v0.3.0`/`v0.3.1` (backfilled in `CHANGELOG.md`).

## Behavior after release

- Any user with `events.add_event` and patient access can duplicate a
  draft or finalized prescription into a new draft of the same
  patient and edit the copy immediately.
- Cloned items are independent rows without `source_template`;
  `DrugTemplate.usage_count` untouched. Zero migrations.
